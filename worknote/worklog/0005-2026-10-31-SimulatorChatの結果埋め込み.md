0005 SimulatorChat の結果埋め込み
==================================

# 発注

- AgentCore にここから追加変更を行っていく。まず SimulatorChat（simulator-chat-sonnet）を修正する（コードバージョンを変更）
- AI に渡すコンテキストに、シミュレート結果をそれとわかるように埋め込む。現状は、それが「存在しないか」のような勘違いを起こしている
- 実際は埋め込んでいるのに現状の動作になっているなら、原因を調べたいので教えてほしい

- 調べた結果
  - 同じターンの中では、シミュレータの結果を tool_result として渡していた
  - 次のターン以降は渡していなかった。履歴（ChatTurn）は発言の文（content）だけで、内訳（parts）を持たない。仕様にも「ツールのやり取りは次のターンに送らない」とあった（docs/decisions/2026-10-30-シミュレータ.md）
  - そのため LLM から見ると、過去の自分の発言に結果（「大吉でございます」など）が書いてあるだけで、ツールを呼んだ跡が無い
  - ユーザーが見た実際の会話の記録は、この環境の data に無く、確かめていない。上の仕組みが勘違いの原因だというのは Claude の推測
- 修正（コードのみ。Agent 設定・既定のシステムプロンプトは変えていない）
  - ChatTurn に parts を足した。会話・エージェント間対話とも、その Agent 自身の発言にだけ入れる
  - 内訳の simulation に、呼び出しの中身（tool / args / result / ok）を足した
  - 前のターンの発言を、内訳から tool_use / tool_result のやり取りに戻して送る。tool_use の id は `history_{seq}_{i}` で作る
  - 今見せていないシミュレータの呼び出しと、中身を持たない古い内訳は、「［シミュレータの実行記録（このとき実際にシミュレータが返した結果）］」を付けた文として送る
  - コードを変えたので、既存の会話も次のターンからこの動作になる（ソースのハッシュは変わる）
  - 「コードバージョンを変更」は、AgentCore を別の id で増やすのではなく、今のコードを直すことと Claude が解釈して進めた（確かめてはいない）
