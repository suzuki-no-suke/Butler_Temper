TC0003 対話用テンプレートの内部名（技術的負債）
==============================================

# 内容

画面・資料で「テンプレート」から「対話用テンプレート」に呼び方を改めたが、表・コード・API の名前は template のまま残している。技術的負債としてキープし、今は直さない。


# 項目

## A. 対話用テンプレートの表・コード・API の名前

- 背景
  - 2026-10-31、Agent 設定に埋め込む「Agent テンプレート」を作った。それまでの「テンプレート」（会話用エージェントのプロンプトに埋め込む台本など）は、混ざらないように「対話用テンプレート」と呼ぶことにした
  - Agent テンプレートは、表 agenttemplate / agenttemplateversion、API /api/agent-templates、書き方 {{agent_template:名前}} で、最初から分けて作った
- 決まっていること
  - 改名は画面と資料だけ。DB の名前などはそのままにし、そのことを記録しておく（2026-10-31 ユーザー回答。Claude が「改名の範囲は画面と資料だけか、コード・DB・API まで変えるか」と聞いたことへの答え）
  - 対話用テンプレートの書き方 {{template:名前}} は変えない
- 決まっていないこと
  - いつ、どこまで直すか（表 template / templateversion、dialogue.template_version_ids、API /api/templates、画面の URL /templates、コードの Template / TemplateVersion / referenced_templates / expand_templates など）
- なぜ決める必要があるか
  - 「template」という名前が Agent テンプレートと対話用テンプレートのどちらを指すか、コードを読む人が取り違えやすい
  - 直すときは、DB のマイグレーションと、保存済みのデータ・書き出した設定（設定の中の書き方は変えないので影響は小さい）の扱いが要る
