2026-10-29 履歴と複数の秘密
===========================

# 概要

チャット履歴の一覧・会話の継続と、秘密開示系 Agent で秘密を複数持てるようにした経緯の記録。

## 決まったこと

- チャット履歴の一覧表示（別ページでよい）と、そこからチャット履歴の復元・継続機能をつける（ユーザー指示）
- 秘密開示 AI（secret-keeper と secret-relay）で、秘密の開示条件を複数設定できるようにする（ユーザー指示）

## Claude が決めたこと（未採用の案）

- 履歴ページを /history に置き、ナビゲーションに「履歴」を加える。会話ごとに BOT 名・バージョン・状態・発言数・最初の発言・日時を示し、BOT で絞り込める
- 止まっていない会話は、開いてそのまま続ける
- エラーで止まった会話は「引き継いで続ける」で、同じ BOT 設定のバージョンの新しい会話を作り、エラーより前のやり取りと Agent の状態を写して続ける。止まった会話自体は書き換えない
  - 「エラーを保存して止める」決まりを保ったまま続けられるようにするため
  - 応答を得られなかった最後の発言とエラーは写さない
  - 新しい会話に引き継ぎ元（resumed_from_id）を記録する
- 秘密は secrets に、name・secret・condition の組の一覧で書く。開示済みは状態の disclosed に name の一覧で残す
- secret-keeper : サブはまだ開示していない秘密をまとめて一回で判定し、満たした秘密ごとに開示の発言を作る
- secret-relay : まだ開示していない秘密を Jev の一回の呼び出しで複数の質問として問う。秘密ごとにしきい値と判定の説明を書ける
- 秘密が一つだった頃の設定・状態も読めるようにする（保存済みの古いバージョンを壊さないため）
- 既定の設定の例として「金庫」と「遺言書」の二つの秘密を置く
