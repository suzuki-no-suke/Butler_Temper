2026-10-31 Agent テンプレート
=============================

# 概要

Agent 設定に埋め込む「Agent テンプレート」を作り、それまでのテンプレートを「対話用テンプレート」と呼ぶことにした経緯の記録。

## 決まったこと（ユーザー指示）

- AgentCore の方にもテンプレート機能を付ける。実質、プロンプトを書き換えられる仕組み。ほかの機能は後で考える
- 名前は「Agent テンプレート」。今のテンプレートは「対話用テンプレート」とする。混ざらないようにする
- 埋め込みは、Agent 設定を AgentCore に渡す前にまとめて書き換える。文字列の中に、プロンプトの文字列として埋め込む
- Agent テンプレートのバージョンを変えたら、実行結果も変えたい。付随するテンプレートのバージョンも、会話のプロンプトの記録として残したい。対話用テンプレートとは違い、厳密にバージョン管理し、Agent と同程度の管理を敷く。テンプレートが変わっても Agent は増えないが、実行時の記録はちゃんと増える
- 書き方も分ける（名前も変える）
- 対話用テンプレートへの改名は画面と資料だけ。DB の名前などはそのままにし、そのことを記録する。技術的負債としてキープする
- Agent テンプレートが無ければ、開始時に止める。開始時に、テンプレートの中身までプロンプトに埋め込んで固定する

## Claude が決めたこと（ユーザーの確認は取っていない）

- 書き方は {{agent_template:名前}}。表は agenttemplate / agenttemplateversion、API は /api/agent-templates
- 埋め込みは設定の中の文字列の値ごとに行う（JSON の文字列に埋め込むのではないので、エスケープは要らない）。入れ子にしない
- 会話・エージェント間対話・会話の最初からの並行会話を始めるときに固定する。引き継いだ会話・対話、写した並行会話、採用した会話は、元の記録の固定した設定を引き継ぐ
- Agent テンプレートの仕組みより前の会話・対話は、Agent のバージョンの設定をそのまま使う
- 「Agent と同程度の管理」は、名前が変えられないこと・バージョンと変更メモを積むことまでにした。フォーク・設定変更チャット・書き出しは付けていない（「ほかの機能は後で考える」に従った）
- 画面は、対話用テンプレートと同じ画面の作りを、種類を分けて使う。メニューは Agent 設定の隣
- 技術的負債は worknote/taskcards/TC0003-対話用テンプレートの内部名.md に起票した
