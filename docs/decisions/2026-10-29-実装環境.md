# 追記 : 2026-10-29 言語・管理・DB・データ置き場

## 決まったこと

- Frontend の言語は TypeScript（ユーザー指示）
- Backend の言語は Python。バージョンは Claude に一任され、Claude が 3.14 に決めた
  - 決めた時点で uv が示す安定版の最新が 3.14.6（3.15 は beta）であったため
- ライブラリ管理は uv（ユーザー指示）
- LLM API は BOT ごとに異なるが、まずは Anthropic の API を用いる（ユーザー指示）
- DB は SQLite（ユーザー指示）
- ライブラリのバージョンは指定しない。原則最新を使う（ユーザー指示）
- 採用理由は「いままで使っていたから。現状理解が最も早いスタックだから」（ユーザー指示）
- ルート直下に data（コミットしない）と public_data（コミットする）を置く。data は .gitignore に追加する（ユーザー指示）
- アプリケーションは両方の書き込み先を設定で変更できるようにし、必ず別のフォルダにする（ユーザー指示）
- 機密情報は secrets フォルダに置く。.gitignore には記載済み（ユーザー指示）

## 経緯

  - ルートの data を明示するため `/data/` の行を追加した。既存の `data` の行は消していない


# 追記 : 2026-10-29 パッケージ管理・配信・DB・LLM API・設定・テスト

## 決まったこと

- Frontend のパッケージ管理は npm、ビルドは Vite、Node は最新（ユーザー回答）
- Frontend は Apache などで別途静的配信し、FastAPI は配信しない。実験時は Vite でよい（ユーザー回答）
- ORM は Claude に一任され、ユーザーが「SQLModel でよいはず」とした。SQLModel を採用（ユーザー回答）
- PostgreSQL と SQLite の両対応にする（ユーザー回答）
- マイグレーションは原則 Python スクリプト。ローカルは npm から、リモートは Python で動かす（ユーザー回答）
- data には RAW データ・チャットログの大半、public_data には BOT 設定の全バージョン。ほかは原則 data（ユーザー回答）
- 設定は環境変数。最終的には systemd から読み、ローカルでは secrets.env を使う（ユーザー回答）
- LLM API は初めから切り替え前提。最低限 OpenAI / Gemini / OpenRouter を使えるようにする（ユーザー回答）
- `.gitignore` の既存 `data` 行は許容（ユーザー回答）
- テスト・静的チェックは Claude に一任され、やる方向とされた。Claude が次のとおり決めた
  - Backend : pytest / ruff / mypy
  - Frontend : Vitest / ESLint / tsc

## 経緯

- 実装環境.md の作業手順にある配置先（apps/frontend・apps/backend・apps/migrate）と secrets/secrets.env のパスは、ユーザーの例示・回答から Claude が当てはめたもの
