2026-10-29 Jev 判定 Agent
=========================

# 概要

開示条件の判定に TypeSafe AI の Jev を使い、秘匿情報をメインに伝える Agent（secret-relay）を作った経緯の記録。

## 決まったこと

- シンプルな「一定条件を満たした場合に、秘匿情報をメインに伝える」Agent を作る（ユーザー指示）
- 開示条件を満たしたかの判定を、TypeSafe AI 社の Jev を使った機構で行う（ユーザー指示）
- メイン AI は Sonnet 5.5（ユーザー指示）
- API キーは BT_TYPESAFE_API_KEY として環境に保存済み。それを使って疎通確認まで行う（ユーザー指示）

## Claude が決めたこと（未採用の案）

- Jev への質問は、はい／いいえの確率を返す noul 型にし、確率が threshold（既定 0.8）以上なら開示する
- 判定はメインの応答の前に行い、開示済みなら同じターンからメインに秘匿情報を渡す
- Jev には直近 5000 文字の会話を、話者と発言の JSON として渡す
- 一度開示したら以後は判定しない（disclose_once。既定 true）
- Jev のモデルは別名 jev-latest。固定の版の名前を API で確かめられていないため
- Jev の呼び出しは typesafe-sdk（Python、0.7.5）を使う。記録した本文を読めるよう圧縮（zstd）は切り、リトライもしない
- 疎通確認の道具を tools/check_connectivity.py に置き、npm run check:connectivity で実行する
