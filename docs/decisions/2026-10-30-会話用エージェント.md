2026-10-30 会話用エージェント
============================

# 概要

会話用エージェント（ConversationAgent）・テンプレート・エージェント間対話を作った経緯の記録。

## 決まったこと（ユーザー指示）

- 自分が作った Agent と会話するための Agent として「会話用エージェント」（英語では ConversationAgent）を作る
  - 今の Agent と同じように自由に組めるが、完全に別扱い。対話ページもメニューも別にする
  - 既存の Agent が会話用エージェントになることも、会話用エージェントが Agent に昇格することも無い。同じように見せて全く別のものとして扱う
  - 管理（バージョン・フォークなど）は今の Agent と完全に同じでよい
  - 会話用エージェントは、人間と全く同じ対話の発声しかできない
- 会話するのは会話用エージェントと既存の Agent で、利用者はそれを見る。ページ名は「エージェント間対話」。履歴ページも作る
- 対話は「次の発言を行う」で 1 ターンずつ進める、完全自律のターン制。自動で回すターン数を指定するか、1 ターンだけ進めるかを選ぶ。自動の上限は 50 ターン
- 対話記録の、どちらの発言にも評価を付けられるようにする
- 対話の記録は、全く別の会話体系として残す（構造が不自然になるなら既存の会話の表に足してもよい、とも言われた）
- テンプレート機能を足す。まずは会話用エージェントだけ、プロンプトにテンプレートを埋め込める
  - テンプレートは台本といってよいが、任意のテキスト（サニタイズはする）を埋め込めるようにしたいので汎用の名前にした。入れ子は要らない
  - テンプレートにもバージョンを持たせる
- 最初の会話用エージェントとして、テンプレートに従いそうな会話をできるだけ続けるものを、Sonnet 5.5 と Opus 5.5 で一つずつ作る

## Claude が決めたこと（未決の案として示し、「他の未決案は採用してよさそう」と回答を得たもの）

- 会話用エージェントは、Agent とは別のテーブル（conversationbot など）・別の AgentCore の登録（CONVERSATION_AGENTS）に置く
- テンプレートは名前付きで保存し、プロンプト中の `{{template:名前}}` で埋め込む
- 会話用エージェントの設定画面とテンプレートを書く画面を作る
- seed は、種類ごとに一つも無いときに作る形に変えた（既存の DB にも会話用エージェントが入るように）

## Claude が決めたこと（回答の後、実装しながら決めたもの。未採用）

- 1 ターンは、会話用エージェントの発言と、それへの Agent の応答の一組とした
- 自動で進めるのは、画面が 1 ターンの API を指定の回数呼ぶ形にした。途中で「このターンで止める」ことができる。上限の 50 は画面で守る（API は 1 ターンずつしか進めない）
- エラーが起きたら対話を止め、既存の会話と同じく「引き継いで続ける」で新しい対話を作る。Agent の応答を得られなかった会話用エージェントの発言は引き継がない
- 会話用エージェントの AgentCore は、発言の文と状態だけを返す型（ConversationCore / SpeakResult）にした。表示用の内訳・割込みは出せない
- Agent には割込み要求を渡さない
- テンプレートの名前は作成後に変えられない。名前に `{` `}` と改行は使えない
- テンプレートのサニタイズは、保存時に改行を LF にそろえ、改行とタブ以外の制御文字を除く
- テンプレートは、対話を始めたときの最新バージョンに固定する。設定にあるテンプレートが無ければ対話を始められない
- 会話用エージェントの AgentCore の id は conversation-script-sonnet / conversation-script-opus、名前は「台本に沿って会話を続ける（Sonnet 5.5 / Opus 5.5）」
- 会話の始めに、会話用エージェントへ opening_message（利用者の発言の形）を渡す。LLM API が利用者の発言から始まる必要があるため
- 既定の設定が使う台本のサンプル（台本サンプル）を seed で作る
- 対話全体へのコメントも、既存の会話と同じように付けられるようにした
- RAW の記録は既存の rawcall に dialogue_id を足して置いた（発言ごとに一つ）
- 設定の書き出し（npm run export:bots）に、会話用エージェントを conversation_agents フォルダとして足した
- メニューは、既存の項目の後ろに区切りを置いて「エージェント間対話・対話履歴・会話用エージェント設定・テンプレート」を並べた
