実装環境
========

# 概要

本資料は、アプリケーションの実装に用いる言語・フレームワーク・ライブラリ管理・DB・LLM API、およびデータと機密情報の置き場所を定める。

## 全体像

- 採用理由は、いままで使っていて、現状もっとも理解が早いスタックであるため
- Frontend : TypeScript + React + React Router（HashRouter）
- Backend : Python 3.14 + FastAPI、ライブラリ管理は uv
- DB : SQLite
- LLM API : BOT ごとに異なるが、まずは Anthropic の API を用いる
- ライブラリのバージョンは指定しない（原則最新を使う）
- データ置き場はルート直下の data（コミットしない）と public_data（コミットする）。機密情報は secrets に置く

# データと機密情報の置き場所

アプリケーションのデータは、コミットしない data と、コミットする public_data に分けて置く。リポジトリに残すデータと残さないデータが混ざらないようにするためである。

## 細則

- data : リポジトリにコミットしないデータの保存場所
  - .gitignore に記載する
- public_data : リポジトリにコミットするデータの保存場所
  - 置いたものは Git にコミットする
- アプリケーションは、data と public_data の両方の書き込み先を設定で変更できるようにする
- data と public_data の書き込み先は、必ず別のフォルダにしなければならない
  - 例) 設定で両方を同じフォルダに向けることはできない
- 機密情報は secrets フォルダに置く
  - secrets は .gitignore に記載済み

(決定経緯 : 2026-10-29, docs/decisions/2026-10-29-実装環境.md)
