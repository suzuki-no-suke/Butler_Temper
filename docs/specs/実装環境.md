実装環境
========

# 概要

本資料は、アプリケーションの実装に用いる言語・フレームワーク・ライブラリ管理・DB・LLM API・テスト、およびデータ・設定・機密情報の置き場所を定める。

## 全体像

- 採用理由は、いままで使っていて、現状もっとも理解が早いスタックであるため
- Frontend : TypeScript + React + React Router（HashRouter）、パッケージ管理は npm、ビルドは Vite
- Backend : Python 3.14 + FastAPI、ライブラリ管理は uv、ORM は SQLModel
- DB : SQLite（PostgreSQL にも対応させる）。RAW 用の DB を別に作る
- LLM API : BOT ごとに切り替える前提で作る。まずは Anthropic を用い、最低限 OpenAI / Gemini / OpenRouter も使えるようにする
- ライブラリ・Node のバージョンは指定しない（原則最新を使う）
- 配信 : Frontend は Apache などで静的配信する。FastAPI は Frontend を配信しない
- データ置き場はルート直下の data（コミットしない）と public_data（コミットする）。機密情報は secrets に置く
- 設定は環境変数で渡す
- テスト・静的チェックを行う
  - (※ 現状、LLM API の呼び出しに PydanticAI を使うかは検討中)


# 作業手順

1. Frontend は apps/frontend、Backend は apps/backend、マイグレーションは apps/migrate に置く
2. Python のライブラリは uv、Frontend のライブラリは npm で追加する
3. ローカルでは secrets/secrets.env に設定と機密情報を書いて起動する
4. 変更後は `# テスト・静的チェック` の細則にあるチェックを通す

## 細則

- 言語 : TypeScript
- UI ライブラリ : React
- ルーティング : React Router
  - ルーターは HashRouter を用いる
- パッケージ管理 : npm
- ビルド : Vite
- Node のバージョンは最新を使う
- ライブラリのバージョンは指定せず、原則最新を使う

# DB

DB は SQLite を用い、PostgreSQL にも対応させる。ORM には SQLModel を用いる。ローカルでは手軽な SQLite で動かしつつ、PostgreSQL に移れる余地を残すためである。

## 細則

- DB : SQLite
  - PostgreSQL にも対応させる
- ORM : SQLModel
- LLM API の RAW 入力・出力を保存する RAW 用の DB を、通常の DB とは別に作る
- マイグレーションは、原則 Python スクリプトとして書く
  - リモートでは Python で動かす
  - ローカルでは npm から動かしてよい

(決定経緯 : 2026-10-29, docs/decisions/2026-10-29-実装環境.md)

# データ・設定・機密情報の置き場所

アプリケーションのデータは、コミットしない data と、コミットする public_data に分けて置く。リポジトリに残すデータと残さないデータが混ざらないようにするためである。設定と機密情報は環境変数で渡す。

## 細則

データの置き場所は次のとおり。

- data : リポジトリにコミットしないデータの保存場所
  - .gitignore に記載する
  - RAW データ、チャットログの大半を置く
  - 置き場所に迷うデータは、原則 data に置く
- public_data : リポジトリにコミットするデータの保存場所
  - 置いたものは Git にコミットする
  - BOT 設定の全バージョンを置く
- アプリケーションは、data と public_data の両方の書き込み先を設定で変更できるようにする
- data と public_data の書き込み先は、必ず別のフォルダにしなければならない
  - 例) 設定で両方を同じフォルダに向けることはできない

設定と機密情報は次のとおり。

- 設定は環境変数で渡す
  - 最終的には systemd から環境変数を読み込ませる
  - ローカルでは secrets.env を用いる
- 機密情報は secrets フォルダに置く
  - secrets は .gitignore に記載済み

(決定経緯 : 2026-10-29, docs/decisions/2026-10-29-実装環境.md)
