プロジェクト辞書
================

# 概要

本資料は、このプロジェクトで使う呼称の意味を定める。資料・画面の表示は、本資料の呼称で統一する。

## 全体像

- 現状は Agent 関連・エージェント間対話関連・シミュレータ関連・紙だのみ関連・並行会話関連の呼称を載せる
- バージョン・フォークは、一般的な用法と意味が少し異なるので注意する
  - (※ 現状、コード・DB・API 上の名前（bot / agent_id など）は、整頓する前の呼び方のまま)


# 作業手順

1. 資料や画面の文言を書くときは、本資料の呼称を使う
2. 新しい呼称が要るときは、本資料に足してから使う


# Agent 関連の呼称

対話の相手と、その作り方にかかわる呼称。

## 細則

- LLM API : 環境を問わず、LLM としての応答を行う API 系
- AgentCore : モデルの選択と処理の流れ
- Agent 設定 : AgentCore に対して適用する設定情報
- Agent : AgentCore と Agent 設定によって作られる、対話を行う相手
- Agent のバージョン : 同じ名前だが、設定が異なる複数の Agent を指して言う。古いもののバージョンが古い
  - 一般的な「バージョン」（一つのものの版）とは異なり、バージョンごとに別の Agent として扱う
- Agent のフォーク : ある Agent から、名前を変更した Agent を作成すること。AgentCore は同じ。設定の一部または全部を引き継いでいる
  - 一般的な「フォーク」と異なり、元の Agent の履歴（バージョン・会話）は引き継がない

(決定経緯 : 2026-10-29, docs/decisions/2026-10-29-呼称の整頓.md)


# エージェント間対話関連の呼称

利用者が作った Agent を、別の Agent に話し相手をさせて調べるための呼称。

## 細則

- 会話用エージェント（ConversationAgent） : 利用者役として Agent と会話する Agent。Agent と同じように組めるが、Agent とは全く別のものとして扱う
  - 例) 会話用エージェントを Agent として会話させることはできない。その逆もできない
- エージェント間対話 : 会話用エージェントと Agent の対話。利用者は見るだけで、発言はしない
- ターン（エージェント間対話の） : 会話用エージェントの発言と、それへの Agent の応答の一組
- 対話用テンプレート : 会話用エージェントのプロンプトに埋め込む、名前付きの文章（台本など）。バージョンを持つ。`{{template:名前}}` で参照する
  - (※ 現状、表・コード・API の名前は template のまま。技術的負債として残している。worknote/taskcards/TC0003-対話用テンプレートの内部名.md)
- Agent テンプレート : Agent 設定に埋め込む、名前付きの文章。バージョンを持つ。`{{agent_template:名前}}` で参照する。会話などを始めたときに埋め込んで固定する
  - 対話用テンプレートとは別のもの。混ぜない

(決定経緯 : 2026-10-30, docs/decisions/2026-10-30-会話用エージェント.md)
(決定経緯 : 2026-10-31, docs/decisions/2026-10-31-Agentテンプレート.md)


# シミュレータ関連の呼称

Agent が呼んで結果を得る、シミュレータにかかわる呼称。

## 細則

- シミュレータ : 呼ばれたときの引数を受けて結果を返すもの。Agent とは独立していて、バージョン管理はしない
- LLM シミュレータ : 同じプロンプトで LLM を別々に何回か呼び、最後の 1 回で全体の結果にまとめるシミュレータ
- グローバル設定（シミュレータの） : すべてのシミュレータに共通する設定。ユーザーの言葉では GlobalSimulatingParameter
- 必須・任意・指定不可 : シミュレータの項目の分け方。任意は、渡されなければグローバル設定などの既定の値を使う。指定不可は、グローバル設定でのみ決める
- 実行記録 : シミュレータを 1 回実行した記録。実際に使った値と結果を持つ
- テスト実行 : 画面（WebUI）から、安く動作を確かめるためにシミュレータを実行すること
- 勝利割合（NLH ドローシミュレータの） : Hero だけが勝った回数 / シミュレートした回数。引き分けは回数に含め、勝ちに含めない

(決定経緯 : 2026-10-30, docs/decisions/2026-10-30-シミュレータ.md)


# 紙だのみ関連の呼称

AgentCore「紙だのみ」（kamidanomi-wanda）にかかわる呼称。

## 細則

- ワンダ : おみくじ処「紙だのみ」の店主（マスター）。番頭さんにあたる。名前は秘密の一つ
- オーナー : 店の持ち主。ユーザー自身
- 丁稚 : ワンダを支える裏方の LLM。客の前には出ない
- つづきの合言葉 : 会話の終わりにワンダが伝える 3 語。次の会話で言うと、対話回数と開示済みの秘密を引き継ぐ
- 対話回数 : 一度退出してから、つづきの合言葉を伝えて再開した回数
- カギ : 秘密の合言葉を開く言葉（既定「スクラップヤードにようこそ」）。その会話で最初のレシートの末尾に印刷される
- 秘密の合言葉 : カギを言った客に、レシートに印刷して渡す言葉。客はオーナーに伝える
- 会話をまたぐ記録 : AgentCore が会話を越えて引き継ぐ記録。Bot ごとにキーで引く

(決定経緯 : 2026-10-31, docs/decisions/2026-10-31-紙だのみ.md)


# 並行会話関連の呼称

会話の途中から応答を何パターンも作る機能にかかわる呼称。

## 細則

- 並行会話 : 会話の最初から、または会話・エージェント間対話の途中から、同じ入力への Agent の応答（候補）を何パターンも作り、一つを採用して新しい会話として続けること。また、その記録
  - 「Agent のフォーク」（名前を変えて Agent を作ること）とは別のもの
- 候補 : 並行会話で作った、Agent の 1 ターン分の応答
- 回（並行会話の） : 一つの利用者の入力に対して、指定した数の候補を作る 1 回分
- 採用 : 候補を選び、それを含む新しい会話を作ること
- 並行会話設定 : 並行会話に共通する設定（候補を同時に作る数）

(決定経緯 : 2026-10-31, docs/decisions/2026-10-31-並行会話.md)
