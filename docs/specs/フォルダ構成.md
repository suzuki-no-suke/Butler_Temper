フォルダ構成
============

# 概要

本資料は、リポジトリのルート直下と docs 配下のフォルダ構成、および docs 配下のファイル名の付け方を定める。

## 全体像

- ルート直下には apps / tools / docs を置く（作業用の worknote も置く）
  - ほかにデータ置き場の data / public_data と、機密情報置き場の secrets を置く
  - apps : 構築済みアプリケーション
  - tools : アプリケーション動作の外側にあるもの（環境管理系が主）
- docs 配下には specs / knowhows / decisions を置く
  - specs : 確定した事項
  - knowhows : 外部から獲得した知識
  - decisions : 何かを決めた経緯などの記録
- フォルダ構成についての規約（本資料）は docs/specs に置く
- 作業指示・作業記録は worknote に置く（規約は .claude/rules/worknote_folder.md）


# 作業手順

1. 置こうとしているものが、アプリケーションそのものか、その外側の道具か、資料かを判断する
2. アプリケーションそのものなら apps、外側の道具なら tools に置く
3. 資料のうち、確定した事項は docs/specs、外部から獲得した知識は docs/knowhows、決めた経緯は docs/decisions に置く
4. 未決・作業中のものは worknote に置く（未決事項は taskcards に置く）
5. docs 配下に置くときは `# docs 配下のファイル名` に従って名前を付ける


# ルート直下の配置

ルート直下には apps / tools / docs を置き、アプリケーションそのものは apps、アプリケーション動作の外側にあるものは tools に分ける。アプリケーションの動作に必要なものと、それを管理・保守するための道具とを混ぜないためである。

## 細則

- ルート直下に置くフォルダは次のとおり
  - apps
  - tools
  - docs
  - worknote（作業用。.claude/rules/worknote_folder.md で定める）
  - data（コミットしないデータの保存場所。.gitignore に記載）
  - public_data（コミットするデータの保存場所）
  - secrets（機密情報の置き場所。.gitignore に記載）
  - data / public_data / secrets の扱いは docs/specs/実装環境.md で定める
- apps には構築済みアプリケーションを置く
  - 例) frontend / backend / migrate などのフォルダを置く
- tools にはアプリケーション動作の外側にあるものを置く。環境管理系が主になる
  - 例) DB のバックアップ、リストア、デバッグ、設定のバリデーション
- 中身がまだ無いフォルダは .gitkeep を置いて保持する

# 確定事項の保管（docs）

確定済みの事項・獲得した知識・決定の経緯は docs 配下に保管する。docs を見れば確定したものだけが分かる状態を保つためである。

## 細則

- docs 配下には次のフォルダを置く
  - specs : 確定した事項
  - knowhows : 外部から獲得した知識
  - decisions : 何かを決めた経緯などの記録
- フォルダ構成の規約（本資料）は docs/specs に置く
- 未決・検討中の事項は docs に置いてはならない（worknote/taskcards に置く）
- worknote/usernotes の資料は絶対に移動・改変しない
  - usernotes の内容を specs に改めて整頓して書き出すことはある。その場合も元の usernotes はそのまま残す

(決定経緯 : 2026-10-29, docs/decisions/2026-10-29-フォルダ構成.md)


# docs 配下のファイル名

docs 配下のファイル名は、フォルダごとに次の形で付ける。decisions だけは日付を先頭に付け、決定の順に並ぶようにする。

## 細則

- specs / knowhows : `(主題).md`
  - 例) docs/specs/フォルダ構成.md
- decisions : `YYYY-MM-DD-(主題).md`
  - 日付は決定した日とする
  - 例) docs/decisions/2026-10-29-フォルダ構成.md
- 主題は日本語でよい
